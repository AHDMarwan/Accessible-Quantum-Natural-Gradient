# AQNG manuscript source policy

The manuscript in `paper/manuscript/` is a clean rewrite. Its scientific inputs are restricted to:

1. the committed frozen AQNG result package under `results/paper/paper_scale_v2/`;
2. the AQNG implementation and experiment code in this repository;
3. the prior-paper lineage listed in `references.bib`;
4. additional primary literature checked explicitly during writing.

Numerical claims must be regenerated or checked against the committed v2 tables. The unpublished spectral-geometry manuscript is cited temporarily as an unpublished manuscript until a permanent identifier is available.

The superseded AQNG draft and the earlier `paper_main_v1` result package were removed from the canonical `main` tree during repository cleanup and are not source text for this manuscript.
